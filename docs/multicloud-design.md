# 多云版本设计与实现计划

用户已授权在已有软件中增加云厂商选择，并在完成后清理测试及无用数据。此次选择阿里云 ECS、腾讯云 CVM、华为云 ECS、AWS EC2；保留一次监控一台服务器及1.0.6显示窗口重建方案。

使用各平台官方.NET SDK读取监控API，而非抓网页或在服务器安装自制采集服务。各平台已有监控Agent未报告的指标保持灰色并说明原因。统一使用百分比、bit/s和真实采样时间；AWS默认网络指标包含全部网卡收发，在界面明确其口径。

设置增加厂商选择、动态字段说明及华为项目ID；凭证按厂商隔离并继续用当前Windows用户DPAPI加密。旧配置未包含厂商时视为阿里云。切换时保留各厂商已保存的配置；不将旧厂商密钥发送给新厂商。

实现步骤：

1. Core增加CloudVendor和配置校验，App建立ICloudMonitorProvider/路由；先添加旧配置及跨厂商凭证阻断回归，再实现。
2. 三个独立适配器使用官方SDK；每个适配器有响应解析、时间及单位测试；独立失败保留其他指标，异常仅输出固定安全提示。腾讯磁盘指标为最大盘汇总，禁止伪装支持固定设备。
3. 配置存储增加向后兼容的分厂商档案；设置界面切换载入、凭证标签/地域提示、项目字段、网络口径及固定磁盘能力同步变化。切换保存清空旧指标缓存并取消旧请求。
4. 运行核心、配置和真实窗口生命周期测试；只读代码审阅；构建1.1.0自包含x64程序、源码和中文配置说明；更新现有桌面安装。
5. 所有验证完成后，校验绝对路径在工作区内再清理历史发布、临时探针/拖动记录、构建输出及不再需要的下载/中转数据。保留最新交付、源码、测试源码、SDK/依赖以便后续维护；安装目录保留一份已确认可用的1.0.6回退程序，清理更早备份。

验收重点：厂商切换不串用密钥/指标、旧DPAPI配置可读、部分缺失灰色、零值与缺失区分、网络单位/周期、多磁盘筛选/分页、无权限和断网安全错误、显示窗口松手重建继续有效。无真实腾讯/华为/AWS凭证时明确记录未在线联调。
