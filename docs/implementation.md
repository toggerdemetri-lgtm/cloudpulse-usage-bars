# 实现记录

已批准方案：Windows x64 / .NET 10 / WPF，阿里云官方监控 SDK，四条仅桌面层颜色条。

1. 桌面宿主：先用真实 HWND 探针验证挂载、尺寸和宿主类型，再完成交互。
2. 指标核心：先编写失败测试，再实现阈值、带宽换算、时间及设备选择。
3. 配置及取数：DPAPI 本机用户加密，官方 SDK，错误隔离及单次轮询。
4. 集成界面：悬停、设置、托盘、拖动及恢复。
5. 验证交付：自动测试、桌面检查、便携 ZIP 和说明。

决定：目录原为空且没有 Git 仓库，直接在用户指定目录实现，无分支或 worktree 操作。
决定：桌面挂载到 Explorer 的 SHELLDLL_DefView（位于 Progman 或 WorkerW），以保留鼠标命中和桌面图标层级；不发送创建壁纸 WorkerW 的特殊消息。
决定：无真实凭证时不调用云端、不填入模拟监控数据。

独立审阅后修正：桌面尺寸使用固定220×24逻辑尺寸计算，避免WM_SIZE回写属性后重复缩放；取消改为逐指标超时结果，保留成功分项；连接测试执行同一有效性规则，入站旧值明确标记。
