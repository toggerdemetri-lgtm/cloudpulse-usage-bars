# 第三方组件

- .NET 10 / WPF / Windows Forms：Microsoft 与 .NET contributors，MIT 许可证等。[.NET 许可证](https://github.com/dotnet/runtime/blob/main/LICENSE.TXT)、[第三方声明](https://github.com/dotnet/runtime/blob/main/THIRD-PARTY-NOTICES.TXT)。
- AlibabaCloud.SDK.Cms20190101 4.0.11 与其 Tea / OpenAPI 依赖：Alibaba Cloud，Apache-2.0 等。依赖的具体版本和许可证可在 NuGet 包元数据中查看。[SDK 包](https://www.nuget.org/packages/AlibabaCloud.SDK.Cms20190101/4.0.11)、[SDK 源码](https://github.com/aliyun/alibabacloud-csharp-sdk)。
- TencentCloudSDK.Monitor 3.0.1520 及 Common：Tencent Cloud，Apache-2.0。[SDK](https://github.com/TencentCloud/tencentcloud-sdk-dotnet)。
- HuaweiCloud.SDK.Ces 3.1.216 及 Core：Huawei Cloud，Apache-2.0。[SDK](https://github.com/huaweicloud/huaweicloud-sdk-net-v3)。
- AWSSDK.CloudWatch 4.0.107.4 及 Core：Amazon Web Services，Apache-2.0。[SDK](https://github.com/aws/aws-sdk-net)。
- 其他传递依赖随 SDK 的 NuGet 依赖树解析，完整列表可运行 `dotnet list src/UsageIsland.App package --include-transitive` 查看。

本项目只使用以上组件的公开 API，没有复制控制台页面或网页素材。
